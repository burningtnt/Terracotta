    Terracotta | 陶瓦联机

    Terracotta 为游玩 Minecraft: Java Edition 的玩家提供开箱即用的联机功能。

    项目基于 EasyTier 开发，针对 Minecraft 做了大量优化，尽量降低操作门槛，并集成了 HMCL 启动器支持。

    特性

    • 开箱即用：无需注册账号、无需配置端口映射或组网参数，下载后即可使用。
    • 房间码联机：房主创建房间获得房间码，玩家输入房间码即可加入，如同置身同一局域网。
    • 针对 Minecraft 优化：内置 Minecraft 服务扫描与大厅机制，在多人游戏列表中双击「陶瓦联机大厅」即可加入。

    支持平台

    平台 支持
    Windows 10 及以上（x86_64 / ARM64） ✅
    macOS（x86_64 / ARM64） ✅
    Linux（x86_64 / ARM64 / LoongArch64 / RISC-V 64） ✅
    FreeBSD（x86_64） ✅
    Android（JNI） ✅
